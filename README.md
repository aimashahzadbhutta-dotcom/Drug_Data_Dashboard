# Drug Data Dashboard

Welcome to the Drug Data Dashboard repository. This project focuses on building an interactive, insightful web-based or script-driven dashboard designed to explore, visualize, and analyze pharmaceutical and drug-related datasets. 

In modern life sciences and data analytics, transforming complex pharmacological datasets into clear, interactive visual interfaces is essential for identifying drug efficacy, adverse event profiles, chemical properties, or usage trends. This repository documents a structured workflow for parsing drug data and presenting actionable insights through intuitive visualizations.

## Core Analytical Objectives

* **Data Exploration:** Inspecting pharmacological parameters, clinical metrics, or chemical attributes across various compounds.
* **Interactive Visualization:** Translating rows of raw data into dynamic charts, distribution plots, and comparison panels.
* **Streamlined Workflow:** Providing a clean architecture for filtering, aggregating, and querying drug datasets efficiently.

## Repository Architecture


## Getting Started Locally

To clone this repository and run the dashboard locally on your machine, execute the following commands in your terminal:

```bash
git clone https://github.com/aimashahzadbhutta-dotcom/Drug_Data_Dashboard.git
cd Drug_Data_Dashboard
```

Install the required Python packages for data processing and visualization:

```bash
pip install -r requirements.txt
```

Run the application (depending on your setup, e.g., Streamlit, Dash, or Python script):

```bash
streamlit run app.py
```

## Analytical Workflow and Features

1. **Data Ingestion and Cleansing:** Automated loading of drug datasets, handling missing values, and formatting structural attributes.
2. **Interactive Filtering:** Dynamic controls allowing users to filter compounds or categories based on specific clinical or chemical criteria.
3. **Visual Analytics:** Generating comparative plots to evaluate trends, distributions, and correlations within the dataset.
